# RyazhTune

RyazhTune — это пользовательский модуль фоновой музыки для Nintendo Switch. Он позволяет пользователям воспроизводить собственные аудиофайлы во время игрового процесса и навигации по системе. Этот проект является форком оригинальной реализации sys-tune, расширенным дополнительными функциями для улучшения пользовательского опыта и управления конфигурацией.

## Возможности

- **Постоянные плейлисты**: Состояние плейлиста сохраняется при перезагрузках системы.
- **Функция автозапуска**: Настраиваемая автоматическая инициализация воспроизведения при запуске системы.
- **Режимы фильтрации по Title ID**: `Normal` / `Whitelist` / `Blacklist` с per-title настройками в оверлее.
- **Гибкая политика фокуса**: Global `Title Focus` + per-title `Custom Focus` (Play / Pause / Pass), включая отдельное поведение для HOME.
- **Мультиязычный UI**: Поддержка нескольких локалей и отдельный экран выбора языка (двухколоночный формат).
- **Поддержка аудиоформатов**: Встроенное декодирование форматов MP3, FLAC, WAV и WAVE.
- **Интеграция с оверлеем**: Бесшовное управление через интерфейс оверлея Tesla.

## Установка

1. Загрузите последний архив релиза (`.zip`) со страницы релизов репозитория.
2. Извлеките содержимое архива в корневой каталог SD-карты Nintendo Switch.
3. Разместите поддерживаемые аудиофайлы (MP3, FLAC, WAV) на SD-карте.
4. Запустите меню оверлея Tesla для управления воспроизведением и конфигурациями.

## Архитектура и компоненты

Проект состоит из нескольких основных компонентов:

- **sys-tune**: Основной фоновый системный модуль (sysmodule), отвечающий за декодирование и воспроизведение аудио через службу `audren`.
- **overlay**: Плагин оверлея Tesla (`.ovl`), предоставляющий графический пользовательский интерфейс для управления воспроизведением.
- **ipc**: Определения межпроцессного взаимодействия, облегчающие взаимодействие между оверлеем и системным модулем.
- **libtesla**: Встроенная библиотека пользовательского интерфейса для рендеринга интерфейса оверлея.
- **common**: Общие утилиты для управления конфигурацией (`minIni`), доступа к SD-карте и управления процессами.

## Конфигурация

Файлы конфигурации автоматически генерируются при первом использовании и хранятся в `/config/RyazhTune/`. Модуль использует `minIni` для анализа конфигурации.

- `config.ini`: Основные параметры конфигурации (автозапуск, громкость, перемешивание, повтор, язык, фильтрация по Title ID).
- Секции `whitelist` / `blacklist` внутри `config.ini`: per-title флаги для режимов Whitelist/Blacklist.
- `saved_playlist.txt`: Состояние постоянного плейлиста.
- `play_source.txt`: Последний источник воспроизведения (`Playlist` или `Folder:<path>`).

### Поведение фильтрации (TuneMode)

- `Normal`: музыка не фильтруется по Title ID.
- `Whitelist`: музыка разрешена только для Title ID, включённых в `whitelist`.
- `Blacklist`: музыка запрещена для Title ID, включённых в `blacklist`.

## Сборка из исходного кода

### Предварительные требования

- [devkitPro](https://devkitpro.org/) с установленной группой пакетов `switch-dev`.
- Установленный GNU Make.
- Доступность команды `python3` в системном окружении.
- Убедитесь, что переменная окружения `DEVKITPRO` правильно настроена.

### Стандартная сборка

Для компиляции основных компонентов проекта (системного модуля и оверлея):

```bash
make all
```

Для создания архива с готовой структурой для установки:

```bash
make dist
```

### Расширенная сборка (Horizon-OC)

Для сборки с интеграцией изменений Horizon-OC и патчингом Atmosphere:

1. Запустите скрипт автоматической настройки:
   ```bash
   chmod +x setup_build_env.sh
   ./setup_build_env.sh
   ```
2. Скрипт автоматически склонирует необходимые репозитории (Atmosphere, Horizon-OC), применит патч `ldr_process_creation.cpp` и запустит процесс сборки.
